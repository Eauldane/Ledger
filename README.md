# Ledger

Ledger is a Dalamud plugin to help you track unlocked achievements, and owned mounts, TT cards, orchestrion
rolls etc. 

## Installation

Add the following third party repository to your Dalamud settings:

`https://raw.githubusercontent.com/Eauldane/ElfShelf/refs/heads/main/repo.json`

Then check for updates. Ledger should be available for installation from the list.
